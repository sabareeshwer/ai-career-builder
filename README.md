## ⚡ Quick Execution Commands

### 1. Launch Backend API (Port 5000)
```bash
cd ai-career-builder/backend
npm run dev
```

### 2. Launch Frontend Application (Port 5173)
```bash
cd ai-career-builder/frontend
npm run dev
```

### 3. Open in Browser
Open `http://localhost:5173` in your web browser.
Click **"Quick Demo Login"** on the top right to instantly log in as the pre-configured student candidate **Alex Rivera**!
